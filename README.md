# Git Practice

This repository is for practicing basic Git and GitHub workflows.

## Useful Git Commands

- `git status` — Check the current working tree status.
- `git add .` — Stage changes.
- `git commit -m "message"` — Save staged changes in a commit.
- `git push` — Upload local commits to GitHub.
- `git pull` — Fetch and integrate changes from the remote repository.
- `git branch` — List local branches.
- `git switch branch-name` — Switch to another branch.
- `git stash` — Temporarily save uncommitted changes.

## What I Learned

- Creating and switching branches.
- Committing and pushing changes.
- Creating a Pull Request.
- Temporarily saving changes using Git stash.
